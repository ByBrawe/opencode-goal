# OpenCode Goal 1.3.41

OpenCode 2 public-session contract and location-safety hardening release.

## Public V2 session contract

Goal lifecycle interruption now uses the documented OpenCode 2 request shape:

```ts
ctx.session.interrupt({ sessionID, continue: false })
```

The adapter no longer sends the stale `resume` field to `session.interrupt`.
The package keeps the native root/`./server` Plugin.define contract, native-only
`./v2`, TUI `./tui`, shared `./rpc`, programmatic `./api`, and explicit
lazy V1 `./v1` boundaries from 1.3.40.

## Session location safety

Goal state is resolved from the target session returned by `session.get`.
The plugin instance's own options/location are not treated as proof of another
session's directory. If the target session location cannot be resolved, status
and lifecycle operations fail closed without reading or writing Goal state.

Windows storage checks also walk from the canonical project root. This accepts a
legitimate 8.3/long-path alias of the same project while preserving the existing
symlink/junction escape rejection.

## Verification

The release remains gated by the exact-main Windows/Linux package matrix, current
and experimental OpenCode 2 hosts, restart recovery, native sidebar rendering,
Todo differential, host progress, and three-session unit handoff checks. The
trusted publisher also exercises the pinned current Loop V2 companion on
OpenCode 2.0.18 before npm publication.

## Preserved state

Goal identity, objective, constraints, revision, evidence, cumulative usage,
budget state and same-ID handoff recovery are unchanged. No persisted Goal schema
migration or accounting reset is introduced.
