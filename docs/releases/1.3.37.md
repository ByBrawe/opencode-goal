# OpenCode Goal 1.3.37

OpenCode 2 stable-support release.

## Highlights

- OpenCode 2 lifecycle and autonomous continuation are enabled by default.
- The installer uses OpenCode 2's native `plugins` configuration and plugin-native `/goal` command while retaining the OpenCode 1 `plugin` + managed-command path.
- Lifecycle mutation remains host-authenticated, single-use, message-bound, generation-bound, and fail-closed.
- Semantic completion, host evidence, telemetry/accounting, progress, compaction, provider recovery, queue promotion, restart recovery, and Loop coexistence remain tied to the shared V1-quality proof/persistence core.
- Current OpenCode 2.0.15 is covered by an additional stable-host lifecycle gate; the pinned 2.0.11 matrix remains the detailed parity baseline.
- Stock-vs-Goal tool-surface comparison remains explicit: the tested stock OpenCode 2.0.15 provider surface does not expose native `todowrite`, and Goal does not remove stock tools.

## Safety / rollback

The historical V2 environment variables remain explicit kill switches:

```text
OPENCODE_GOAL_V2_DIRECT_LIFECYCLE=0
OPENCODE_GOAL_V2_AUTONOMOUS=0
```

Unknown explicit values fail closed.

## Release gates

The exact 1.3.37 release head must be green across:

- CI
- Actions Security Gate
- Release Readiness
- Real Host Progress
- Real Restart Recovery
- Real Loop Coexistence
- Experimental OpenCode 2 Host (historical name for the pinned 2.0.11 parity matrix)
- Current OpenCode 2 Stable Host
- OpenCode 2 Todo Materialization Diff

Release metadata and the packed V1/V2 installer paths are validated again before publishing.
