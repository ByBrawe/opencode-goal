# OpenCode Goal 1.3.38

OpenCode 2 bounded per-unit session handoff release.

## Bounded native session rotation

A Goal can opt into host-observed work-unit rotation with:

```text
/goal <objective> --unit "<host command>" --fresh-session-per-unit
```

The unit command's stdout is an identity signal only. It never becomes Goal evidence and never proves completion.

When the identity changes after a successful Goal-owned execution, OpenCode Goals uses native OpenCode 2 session primitives to create a fresh child session and moves the same durable Goal through a two-phase handoff. The predecessor is persisted as terminal `handed_off` before the target becomes the autonomous owner.

The handoff preserves the Goal ID, revision, contract, evidence, cumulative usage, budgets, and verification semantics. Paused, waiting-user, blocked/limited, and completed Goals never rotate.

## Crash and concurrency safety

- one Goal-scoped cross-process lease serializes rotation attempts;
- the target inbox ID is selected before admission and reused for resume/retry;
- admission failure leaves the source active;
- target-persistence failure cleans up the newly created native session when supported;
- after the source is terminal, recovery can only continue the persisted target and cannot reactivate the predecessor;
- startup recovery resumes incomplete handoffs without admitting a second inbox message.

## OpenCode 2 native integration

This release also uses the stronger V2 host surfaces where available:

- plugin-native `plugins` entries and `options.lifecycle` / `options.autonomous`;
- `session.hook("prompt")` for early foreground-steering invalidation;
- native tool execution hooks and tool-context progress reporting;
- `session.create`, `session.delete`, and durable `session.prompt` admit/resume identity for unit transfer.

Environment kill switches remain higher-priority fail-closed overrides.

## Release gates

The exact 1.3.38 head must remain green across the normal V1/V2 release suite plus `OpenCode 2 Unit Handoff`, whose current-host canary proves three units cross exactly three native sessions and finish through the normal host + independent semantic completion audit.
