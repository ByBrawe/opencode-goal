# OpenCode Goal 1.3.47

Native Goal sidebar telemetry patch.

## What the sidebar now shows

The OpenCode 2 sidebar remains a read-only projection of persisted Goal state, but
it now exposes enough existing telemetry to act as a useful long-running Goal
dashboard without interrupting the session.

For a live Goal it can show:

- status, completion mode, revision and short Goal id;
- Goal age plus cumulative model runtime accounted from completed assistant turns;
- cumulative turns, tokens and cost with finite or unlimited budgets;
- the configured runtime cap;
- selected model and persisted model-context usage when available;
- required/completed verification counts for requirements, checks and file
  contracts;
- native Todo totals, completed/in-progress/pending counts and the current
  in-progress Todo item;
- age of the last persisted host-progress record and the last Goal-state update;
- continuation-pending, infrastructure-recovery, unit-handoff or active Todo
  lifecycle state when persisted;
- no-progress stall-guard count;
- the ordered Goal queue.

Continuous Goals are labeled `CONTINUOUS` and do not receive a fake completion
percentage.

## Trust boundaries

The sidebar does not invent data the host has not persisted. In particular,
1.3.47 does not claim live tokens/sec, average TPS, a live provider phase or an
estimated completion percentage. Those values require a trustworthy public host
telemetry contract before they can be displayed safely.

Todo state remains advisory planning data and never becomes completion evidence.
The sidebar still does not mutate Goal state or take continuation ownership.

Malformed nested telemetry is ignored or rendered conservatively. An invalid
completion-mode field remains fail-visible as unavailable Goal storage rather than
silently looking like verified mode.

## Compatibility

The telemetry renderer is covered on Linux and Windows, including native OpenTUI
rendering and the location-bound RPC path. The exact-main release gates also retain
current/older OpenCode 2 host coverage, OpenCode 1 compatibility, restart recovery,
Todo differential checks, unit handoff and installed-package smoke.

## Upgrade

```sh
npx -y @bybrawe/opencode-goal@1.3.47
```

Then fully restart OpenCode. The native OpenCode 2 sidebar will render the richer
read-only telemetry automatically when persisted data is available.

Existing Goal state, continuous/verified mode, requirements, evidence, queue state,
budgets and lifecycle ownership are preserved.
