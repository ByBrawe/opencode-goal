# OpenCode Goals 1.3.6 installer hotfix

OpenCode Goals 1.3.6 fixes a Windows/global-config edge case where `/goal` could be discoverable through `commands/goal.md` while the server plugin registration was shadowed by another existing OpenCode config file.

The installer now stages and validates every supported existing global config filename before writing any of them:

- `opencode.json`
- `opencode.jsonc`
- `config.json`
- `config.jsonc`

Every existing config is normalized to the same exact `@bybrawe/opencode-goal@<version>` package pin. If any config is invalid, the multi-config install fails before mutating the real config files.

The existing JSON/JSONC rewrite implementation remains the authority for comment preservation, user-owned `/goal` command protection, local duplicate cleanup, and uninstall behavior.
